# Assets — Sujay OS Kart Arena

**Art direction:** A compact, top-down arcade kart arena that belongs to Sujay Karkera OS: warm sunset peach, burgundy, espresso, cream, coral, and a restrained lime signal accent. The playfield is a crisp pixel-printed workroom circuit with simple, readable game objects rather than photorealistic detail.

| Asset | Purpose | Source |
| --- | --- | --- |
| Kart arena visual target | Composition, palette, HUD, and object-scale reference for the playable game window | `/manus-storage/sujay-os-kart-arena-reference_450d014a.png` |

The playable scene will use lightweight procedural canvas graphics for the karts, track, hazards, crates, particles, and HUD. This keeps controls responsive and ensures the game fits into a draggable OS window while the generated visual target anchors the presentation.
